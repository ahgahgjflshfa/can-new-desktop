# src-tauri — Rust Backend

## OVERVIEW

Tauri 2 Rust backend handling multi-window management, IPC commands, system tray, and notification state.

## STRUCTURE

```
src-tauri/
├── src/
│   ├── lib.rs              # All commands, state, window management
│   └── main.rs             # Entry point (calls lib::run())
├── capabilities/
│   ├── default.json        # Main window permissions
│   └── popup.json          # Popup window permissions
├── gen/schemas/            # Generated (DO NOT EDIT)
├── icons/                  # App icons
├── Cargo.toml              # Dependencies
└── tauri.conf.json         # Tauri config
```

## WHERE TO LOOK

| Task                  | Location              | Notes                                  |
| --------------------- | --------------------- | -------------------------------------- |
| Add new command       | `src/lib.rs`          | Add fn + register in `invoke_handler`  |
| Add window permission | `capabilities/*.json` | Per-window Tauri 2 capabilities        |
| Change popup size     | `src/lib.rs`          | `POPUP_WIDTH`/`POPUP_HEIGHT` constants |
| Modify tray menu      | `src/lib.rs`          | In `setup()` closure                   |
| Add dependency        | `Cargo.toml`          | Run `pnpm check` after                 |

## COMMANDS (lib.rs)

| Command                                           | Purpose                                        |
| ------------------------------------------------- | ---------------------------------------------- |
| `show_alert_popup`                                | Create/show popup, store notification in state |
| `hide_alert_popup`                                | Hide popup window                              |
| `focus_alert_popup`                               | Refocus popup (called every 5s by frontend)    |
| `emit_dismiss_notification`                       | Popup→Main IPC for dismiss                     |
| `get_pending_notification`                        | Popup pulls notification on mount              |
| `set_minimize_to_tray_on_close`                   | Toggle minimize behavior                       |
| `show_emergency_window` / `hide_emergency_window` | Main window control                            |

## STATE MANAGEMENT

```rust
// Shared state via Tauri's manage()
MinimizeToTrayState { enabled: AtomicBool }
PendingNotificationState { notification: Mutex<Option<NotificationPayload>> }
```

- Access in commands: `state: tauri::State<'_, YourState>`
- Both registered in `Builder::default().manage(...)`

## MULTI-WINDOW IPC PATTERN

```
Main Window                              Popup Window
     │                                        │
     │  invoke('show_alert_popup', payload)   │
     ├───────────────────────────────────────►│
     │    1. Store in PendingNotificationState │
     │    2. Create/show WebviewWindow        │
     │    3. emit("show-notification")        │
     │                                        │
     │                                        ├─► onMounted: get_pending_notification()
     │                                        │   (backup if event missed)
     │                                        │
     │  invoke('emit_dismiss_notification')   │
     │◄───────────────────────────────────────┤
     │    emit("dismiss-notification") to main │
```

**Race condition fix:** Popup calls `get_pending_notification` on mount because `show-notification` event may fire before Vue mounts.

## CAPABILITIES (Tauri 2 Permissions)

Each window needs explicit permissions in `capabilities/`:

**default.json** (main window):

```json
["core:default", "core:event:default", "core:event:allow-listen", "core:event:allow-emit", "shell:allow-open"]
```

**popup.json** (alert-popup):

```json
["core:default", "core:event:default", "core:event:allow-listen", "core:event:allow-emit"]
```

## CONVENTIONS

- Commands return `Result<T, String>` for error handling
- Use `map_err(|e| e.to_string())?` for error propagation
- Avoid `unwrap()` except in test code
- Window labels: `"main"`, `"alert-popup"` (match `capabilities/*.json`)
- Debug logs prefixed with `[Rust]`

## ANTI-PATTERNS

| DO NOT                        | WHY                             |
| ----------------------------- | ------------------------------- |
| `unwrap()` in commands        | Crashes app on error            |
| Forget capability permissions | Silent permission denied errors |
| Direct window-to-window emit  | Use Rust as IPC bridge          |
| Edit `gen/schemas/*`          | Generated by Tauri              |

## GOTCHAS

- **Popup close → refocus loop**: X button triggers `on_window_event` which emits `popup-closed` to stop refocus interval
- **Debug builds**: DevTools auto-open via `#[cfg(debug_assertions)]` in setup
- **Window creation**: Uses `WebviewWindowBuilder` with `WebviewUrl::External` (dev) vs `WebviewUrl::App` (prod)
